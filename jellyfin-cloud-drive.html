一、方案原理与优势

传统方案是把网盘里的电影下载到 NAS 硬盘，再用 Jellyfin 扫描播放。这样既占空间又费时间。

使用 CloudMount 的方案：

  1. CloudMount 把百度网盘/阿里云盘挂载成群晖的本地文件夹
  2. Jellyfin Docker 容器直接映射这个挂载目录
  3. Jellyfin 扫描刮削，像本地文件一样播放
核心优势：
  • 不占用 NAS 硬盘空间，网盘有多大媒体库就有多大
  • 不用下载，添加资源后 Jellyfin 立即能看到
  • 自动刮削海报、简介、字幕，体验跟本地完全一样
  • 支持百度网盘、阿里云盘、夸克网盘等 8 大网盘

二、准备工作

  • 一台 x86_64 架构的群晖 NAS（DS220+、DS920+、DS224+ 等）
  • DSM 7.0 及以上系统
  • 已安装 Docker（套件中心搜索安装）
  • 已部署 Jellyfin Docker 容器
  • 百度网盘 / 阿里云盘 / 夸克网盘会员（建议超级会员，速度更稳）

三、第一步：安装 CloudMount 并挂载网盘

1. 下载安装 CloudMount

  1. 访问 CloudMount 官网下载 SPK 安装包
  2. 群晖 DSM → 套件中心 → 手动安装 → 选择 SPK 文件
  3. 点击下一步完成安装

下载 CloudMount →

2. 挂载你的网盘

  1. 打开 CloudMount
  2. 点击「添加网盘」
  3. 选择你要挂载的网盘（百度网盘 / 阿里云盘 / 夸克网盘等）
  4. 扫码登录你的网盘账号
  5. 设置挂载路径，例如：/volume1/CloudMount/百度网盘
  6. 点击确定，等待挂载完成
提示：挂载完成后，在 File Station 中确认一下路径是否正确，能否正常看到网盘里的文件。

四、第二步：配置 Jellyfin 容器

1. 停止 Jellyfin 容器

打开 Docker → 容器 → 找到 Jellyfin → 点击「停止」。

2. 编辑容器，添加挂载目录

  1. 选中 Jellyfin 容器 → 点击「编辑」
  2. 进入「卷」选项卡
  3. 点击「添加文件夹」
  4. 选择 CloudMount 挂载的网盘目录，例如：
    /volume1/CloudMount/百度网盘/电影
  5. 设置装载路径（容器内路径），例如：/media/baiduyun-movies
  6. 同样的方式添加电视剧、动漫等其他分类目录
  7. 点击「应用」保存
建议：把电影和电视剧分开挂载，这样 Jellyfin 刮削更准确。如果你有多个网盘，都可以分别添加。

3. 启动 Jellyfin

选中容器 → 点击「启动」，等待 Jellyfin 完全启动。

五、第三步：在 Jellyfin 中添加媒体库

  1. 打开 Jellyfin Web 管理界面
  2. 进入「控制台」→「媒体库」
  3. 点击「添加媒体库」
  4. 内容类型选择「电影」
  5. 显示名称可以填「百度网盘电影」
  6. 点击「文件夹」→ 「+」→ 选择 /media/baiduyun-movies
  7. 配置好刮削元数据的选项（建议勾选下载海报、简介、字幕等）
  8. 点击「确定」
  9. 重复以上步骤添加电视剧、动漫等其他媒体库
完成！Jellyfin 会开始扫描网盘里的视频文件并自动刮削海报和元数据。根据文件数量，扫描可能需要几分钟到几十分钟。扫描完成后就可以直接播放了！

六、优化技巧与注意事项

1. 刮削速度优化

  • 第一次扫描会比较慢，因为需要读取所有文件并下载元数据
  • 建议先添加少量文件测试，确认没问题再添加全部
  • 可以在 Jellyfin 中设置定时扫描，避免手动刷新

2. 播放流畅度

  • 建议使用有线网络连接 NAS，Wi-Fi 可能不稳定
  • 如果是 4K 视频，确保你的网络带宽足够（至少 50Mbps）
  • 网盘会员速度更快，超级会员基本能跑满带宽
  • Jellyfin 的转码功能需要 NAS 有一定的 CPU 性能

3. 文件命名规范

  • 电影文件建议命名格式：电影名 (年份).mkv
  • 电视剧建议：剧名/Season 01/S01E01.mp4
  • 规范的命名可以大幅提高刮削准确率

4. 字幕

  • Jellyfin 可以自动下载外挂字幕
  • 如果视频已经内封字幕，直接播放时选择即可
  • 也可以把字幕文件和视频放在同一目录

七、常见问题 FAQ

Q：播放卡不卡？需要多大带宽？

A：1080P 视频一般 10-20Mbps 就够了，4K 视频建议 50Mbps 以上。网盘会员速度快，基本不会卡。非会员可能有限速，体验会差一些。

Q：Jellyfin 转码会有问题吗？

A：如果是直接播放（同编码、同容器），不需要转码，体验最好。如果需要转码，取决于 NAS 的 CPU 性能。支持硬件转码的机型（带核显的 Intel CPU）效果更好。

Q：能同时用多个网盘当媒体库吗？

A：可以。CloudMount 支持同时挂载多个网盘（百度/阿里/夸克等），每个网盘分别映射到 Jellyfin 的不同目录，添加多个媒体库就行。

Q：Emby 或 Plex 能用这个方案吗？

A：完全可以。原理是一样的，都是把挂载目录映射到 Docker 容器里，然后添加媒体库。操作步骤基本相同。

Q：会不会封号？

A：正常使用不会。CloudMount 通过官方 API 访问网盘，合理使用频率是安全的。但建议不要短时间内大量并发播放或极端操作。

Q：Video Station 也能直接用吗？

A：可以。CloudMount 挂载的目录 Video Station 可以直接识别并添加为视频库，比 Jellyfin 更简单，但功能和刮削效果不如 Jellyfin。

Q：支持 ARM 机型吗？

A：目前 CloudMount 只支持 x86_64 架构的群晖机型，ARM 机型（DS223j、DS120j 等）暂不支持。
