一、为什么要在群晖上挂载百度网盘？

百度网盘是国内用户量最大的网盘，很多人在里面存了大量电影、音乐、资料。但有了群晖 NAS 之后，你可能会遇到这些痛点：

  • 网盘里的电影想看的时候得先下载到 NAS，太麻烦
  • NAS 硬盘空间不够，但网盘有好几 TB 空间浪费着
  • 管理文件要分别开网盘客户端和 File Station，效率低
  • 想在 Jellyfin/Video Station 里直接看网盘里的电影，做不到

把百度网盘挂载成群晖的本地文件夹，这些问题就都解决了。

三、CloudMount 安装教程

第一步：下载安装包

访问 CloudMount 官网下载对应你群晖机型的 SPK 安装包。支持所有 x86_64 架构机型，包括：

  • DS220+、DS920+、DS720+、DS420+
  • DS224+、DS423+、DS923+
  • DS1522+、DS1821+、DS1621+
  • 以及其他 x86_64 架构的群晖机型
注意：ARM 架构机型（如 DS223j、DS120j、DS218play 等）目前暂不支持。

前往官网下载 →

第二步：安装套件

  1. 打开群晖 DSM 管理界面
  2. 进入「套件中心」
  3. 点击右上角「手动安装」
  4. 选择下载的 SPK 文件
  5. 点击「下一步」，同意用户协议
  6. 点击「完成」

安装完成后，你可以在群晖菜单中找到 CloudMount。

第三步：添加百度网盘

  1. 打开 CloudMount
  2. 点击「添加网盘」
  3. 选择「百度网盘」
  4. 使用百度网盘 APP 扫码登录
  5. 设置挂载路径（默认 /CloudMount/百度网盘）
  6. 点击「确定」完成挂载
完成！现在打开 File Station，你就能在 /CloudMount/百度网盘 目录下看到你百度网盘里的所有文件了，跟本地文件夹一模一样。

四、使用场景与技巧

1. Video Station 直接播放

把电影存在百度网盘里，Video Station 可以直接索引和播放：

  1. 打开 Video Station
  2. 进入「设置」→「视频库」
  3. 添加文件夹，选择挂载的百度网盘电影目录
  4. 确定后 Video Station 会自动扫描刮削

2. Jellyfin / Emby 挂载

如果你用 Docker 版的 Jellyfin 或 Emby，可以直接把挂载目录映射到容器里：

  1. 在 Docker 中编辑 Jellyfin 容器
  2. 添加挂载文件夹：/volume1/CloudMount/百度网盘/电影 → /media/baiduyun
  3. 重启容器
  4. 在 Jellyfin 中添加媒体库，选择 /media/baiduyun

3. 文件管理技巧

  • 挂载后可以直接在 File Station 中复制、移动、重命名文件
  • 可以把多个百度网盘账号同时挂载，统一管理
  • 支持和阿里云盘、夸克网盘等其他挂载的网盘之间互传文件

五、常见问题 FAQ

Q：挂载后下载速度怎么样？

A：取决于你的百度网盘会员等级和网络带宽。超级会员基本能跑满带宽，非会员会有限速。建议在使用高峰期避开拥堵时段。

Q：会被百度封号吗？

A：CloudMount 使用百度官方 API 接口，正常使用不会封号。但建议不要短时间内大量下载或频繁操作，避免触发风控。

Q：ARM 机型能用吗？

A：目前只支持 x86_64 架构的群晖机型，ARM 机型（DS223j、DS120j、DS218play 等）暂时不支持。

Q：数据安全吗？

A：CloudMount 只在本地运行，所有数据通过官方 API 传输，不经过第三方服务器。登录也是在百度官方页面完成的，账号密码不会泄露。

Q：免费吗？有没有功能限制？

A：完全免费，无广告，无功能限制。所有网盘都可以免费挂载。

Q：支持同时挂载多个百度网盘账号吗？

A：支持。你可以添加多个百度网盘账号，每个账号独立挂载到不同路径，统一在 File Station 中管理。

Q：群晖 DSM 7.x 支持吗？

A：支持 DSM 7.0 及以上所有版本，包括最新的 DSM 7.2。

Q：跟官方百度网盘套件有什么区别？

A：官方百度网盘套件只有同步功能，文件会占用本地空间。CloudMount 是纯挂载模式，不占用本地存储空间，而且 File Station 原生集成，体验更好。
