一、115网盘挂载到群晖的优势

115网盘以大容量和离线下载著称，是很多资源党的首选。但115的客户端体验一般，挂载到群晖 NAS 之后体验会有质的飞跃：

  • 离线下载秒看：115离线下载的资源，不用下载到本地，挂载后直接播放
  • 速度快：115网盘下载速度快，挂载后播放流畅
  • 空间大：115会员有好几 TB 空间，相当于给 NAS 扩容
  • 管理方便：File Station 统一管理所有网盘，不用开115客户端
  • 多端播放：电视、手机、电脑都能通过 Jellyfin/Video Station 播放

二、安装教程（3步搞定）

第一步：下载安装 CloudMount

去官网下载对应你群晖机型的 SPK 安装包，支持所有 x86_64 架构机型。

前往官网下载 →

第二步：安装套件

  1. 打开群晖 DSM → 套件中心
  2. 点击右上角「手动安装」
  3. 选择下载的 SPK 文件
  4. 下一步 → 同意协议 → 完成

第三步：添加115网盘

  1. 打开 CloudMount
  2. 点击「添加网盘」→ 选择「115网盘」
  3. 使用115 APP 扫码或输入账号密码登录
  4. 设置挂载路径，点击确定
完成！打开 File Station，你就能看到115网盘里的所有文件了。115离线下载的资源直接就能看到和播放。

三、离线下载资源使用技巧

1. 离线下载后直接播放

在115里用离线下载保存的电影、电视剧，挂载后在 File Station 里直接就能找到，用 Video Station 或 Jellyfin 直接播放，完全不需要下载到 NAS。

2. 资源整理分类

建议在115网盘里把资源按电影、电视剧、动漫等分类建好文件夹，挂载后目录结构一目了然，Jellyfin 刮削也更准确。

3. 配合其他网盘使用

可以同时挂载百度网盘、阿里云盘、115网盘等多个网盘，所有资源在 File Station 里统一管理。还可以在不同网盘之间互传文件。

四、使用场景

1. 家庭影院

115离线下载的高清资源，挂载到群晖后用 Jellyfin 搭建家庭影院，电视、投影、手机、平板都能看。

2. 资源备份迁移

重要资源在115和本地之间双向备份，或者从115迁移到其他网盘，挂载后直接拖拽操作。

3. 共享给家人

通过群晖的共享功能，把115网盘里的影视资源共享给家人使用，每个人都有自己的播放进度和收藏。

五、常见问题 FAQ

Q：115网盘挂载速度怎么样？

A：115网盘本身速度不错，会员速度更快。挂载后的实际速度取决于你的网络带宽和115账号等级，一般能跑到带宽的 60%-80%。

Q：必须要有115会员吗？

A：不是必须的，但115的很多功能（离线下载、大容量等）只有会员才有。而且会员的速度和稳定性都更好。如果你经常用115，建议开通会员。

Q：115离线下载的文件能直接挂载吗？

A：可以。离线下载保存到你自己的115网盘后，挂载目录里就能看到，跟普通文件一样使用。

Q：支持同时挂载多个115账号吗？

A：支持。可以添加多个115网盘账号，分别挂载到不同目录。

Q：115会不会封号？

A：CloudMount 使用官方 API 接口，正常使用不会有问题。但请遵守115的服务条款，合理使用。

Q：和百度网盘比哪个好？

A：各有优势。百度网盘资源多、用户基数大；115离线下载强、速度快。建议两个都挂载，按需使用。CloudMount 支持同时挂载多个网盘。
