安装教程

3步完成安装

群晖 NAS 套件手动安装流程，简单快捷。

1

下载 SPK 安装包

从下方百度网盘链接下载 webdav-mounter_x86_64.spk 文件到本地电脑。

提示：提取码为 9wdx，建议使用百度网盘客户端下载以获得更稳定速度。
2

群晖套件中心手动安装

登录群晖 DSM 管理界面 → 打开「套件中心」→ 点击右上角「手动安装」→ 选择下载好的 .spk 文件 → 点击下一步完成安装。

提示：安装过程中可能提示「发布者不受信任」，此为正常现象，点击「继续安装」即可。需在 DSM 控制面板中开启 SSH 或允许第三方套件安装。
3

打开 CloudMount 并添加网盘

安装完成后在 DSM 主菜单找到 CloudMount 图标并打开 → 点击「网盘」→「新增」→ 选择网盘服务并登录授权 → 设置挂载路径 → 完成挂载。

提示：建议挂载路径使用 /volume1/网盘名称 的格式（如 /volume1/baidu），方便 File Station 中统一管理。FUSE 挂载权限已全自动化，无需手动配置。

常见问题

你可能想问的

CloudMount 支持哪些群晖 NAS 型号？
CloudMount 的 SPK 安装包为 x86_64 架构，支持所有搭载 Intel/AMD 处理器的群晖 NAS 型号（如 DS220+、DS920+、DS1522+、DS224+、DS423+ 等 Plus 系列及 XS 系列）。基于 ARM 架构的 value 系列 NAS（如 DS220j、DS223j 等）暂不支持。
挂载网盘后会占用 NAS 本地存储空间吗？
几乎不会。CloudMount 采用 FUSE 技术将网盘挂载为虚拟目录，文件实际存储在云端，仅在读取/传输时使用少量缓存空间（默认 1GB 缓存上限）。你可以在系统状态中实时监控缓存使用情况，缓存会在空闲时自动清理。
使用 CloudMount 需要开通网盘会员吗？
基础挂载功能不需要网盘会员即可使用。但部分网盘（如百度网盘）对非会员有下载速度限制，建议对速度有要求的用户开通相应网盘的会员服务以获得最佳体验。CloudMount 本身的 VIP 会员可解锁更多高级功能。
跨盘传输是如何工作的？速度怎么样？
跨盘传输采用缓存代理模式：先从源网盘下载文件到 NAS 缓存，再上传到目标网盘。传输速度取决于两个网盘的 API 限速。实测天翼云盘、夸克网盘等速度较快（可达 8MB/s+），百度网盘非会员速度较慢（约 200KB/s）。支持自动重试机制确保传输可靠性。
安装时提示「发布者不受信任」怎么办？
这是群晖 DSM 对非官方套件的正常安全提示。CloudMount 为第三方开发套件，未在群晖套件中心上架。在安装弹窗中点击「继续安装」即可，不影响正常使用。如无法安装，请在 DSM 控制面板 → 安全中允许安装任何发布者的套件。
挂载的网盘能被其他 NAS 应用访问吗？
可以。挂载后的网盘目录出现在 /volume1/ 下，与普通 NAS 文件夹无异。Video Station、Music Station、Synology Photos、Docker 容器等均可直接访问这些目录，实现媒体在线播放、容器存储扩展等功能。
