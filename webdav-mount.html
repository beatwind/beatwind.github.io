一、WebDAV 是什么？为什么用它挂载网盘

WebDAV（Web Distributed Authoring and Versioning）是建立在 HTTP 之上的文件传输协议，可以把远端服务器上的目录当作本地文件夹来读写。群晖 DSM 的 File Station 原生支持 FTP、SFTP、WebDAV 和 WebDAV HTTPS 等协议，因此很多用户会想到用 WebDAV 把网盘挂载到 NAS。

它的优点是通用、无额外套件即可连接：只要对方服务开放了 WebDAV 接口，你就能在群晖上把它挂成一个目录，配合 File Station 浏览、下载与播放。

二、方法一：File Station 远程连接挂载

如果目标服务已经提供 WebDAV 地址（含账号密码），可以直接用 File Station 的远程连接挂载，全程图形界面，无需安装额外套件。

  1. 打开 File Station，进入 工具 > 远程连接 > 连接设置
  2. 点击图标选择协议，勾选 WebDAV 或 WebDAV HTTPS，点击「下一步」
  3. 在弹出窗口中按向导填写远端地址、端口、账号与密码，完成身份验证
  4. 设置完成后，远端服务会出现在 File Station 的左侧面板中，像本地目录一样浏览
提示：WebDAV HTTPS 会加密传输，更安全；如果对方只提供 HTTP 的 WebDAV，注意不要在不可信网络下传输敏感文件。

三、方法二：安装 WebDAV Server 对外提供服务

如果你想让另一台设备（比如手机、电脑或其他 NAS）反过来访问你的群晖，可以在群晖上安装 WebDAV Server 套件，把群晖的共享文件夹以 WebDAV 形式对外提供。

  1. 在套件中心安装并启动 WebDAV Server
  2. 前往 设置 > HTTP/HTTPS，勾选「启用 HTTP」和「启用 HTTPS」
  3. 确认端口号：默认 HTTP 为 5005、HTTPS 为 5006，可按需自定义
  4. 点击「应用」，随后即可在 File Station 或第三方客户端中通过 位置 > 连接至服务器 连入

需要注意，套件对外提供服务时，务必开启防火墙与账号权限控制，避免把共享目录暴露给未授权访问。

四、WebDAV 挂载国内网盘的局限

WebDAV 虽然通用，但用它挂载国内网盘时有几个现实问题，值得提前了解：

  • 接口不开放：百度网盘、阿里云盘、夸克网盘等主流国内网盘大多不直接对外提供 WebDAV 接口
  • 需第三方中转：想挂载这些网盘，通常要借助 Alist 之类的服务把网盘协议转换成 WebDAV，部署和排错门槛较高
  • 多盘管理繁琐：WebDAV 一般一次连接一个远端服务，要挂载多个网盘就得反复添加连接
  • 缺少原生能力：WebDAV 只是文件协议，不带离线缓存、跨盘传输、扫码登录等网盘专属功能

六、常见问题 FAQ

Q：群晖 File Station 支持 WebDAV 吗？

A：支持。在 File Station 中通过 工具 > 远程连接 > 连接设置，可选择 WebDAV 或 WebDAV HTTPS 协议连接远端服务，设置完成后远程目录会显示在左侧面板中。

Q：群晖 WebDAV 默认端口是多少？

A：启用 WebDAV Server 套件时，默认 HTTP 端口为 5005，HTTPS 端口为 5006，可以在 设置 > HTTP/HTTPS 中按需自定义端口号。

Q：百度网盘、阿里云盘支持 WebDAV 直接挂载吗？

A：国内主流网盘大多不直接对外提供 WebDAV 接口，通常需要借助 Alist 等第三方服务做协议转换，配置门槛较高。希望直接挂载国内网盘时，CloudMount 一键挂载更省事。

Q：WebDAV 挂载和 CloudMount 挂载有什么区别？

A：WebDAV 是通用文件协议，适合逐台配置支持 WebDAV 的服务，通常只能一次挂载一个远端；CloudMount 则原生集成到群晖，一次扫码即可挂载 8 大网盘，并支持跨盘传输和离线缓存。
