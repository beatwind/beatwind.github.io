1. What Is WebDAV and Why Mount Drives With It

WebDAV (Web Distributed Authoring and Versioning) is a file transfer protocol built on top of HTTP. It lets you read and write a remote server's directory as if it were a local folder. Synology DSM's File Station natively supports FTP, SFTP, WebDAV and WebDAV HTTPS, which is why many users try to mount cloud drives to the NAS over WebDAV.

Its advantage is being generic and requiring no extra package: as long as the other side exposes a WebDAV endpoint, you can mount it as a directory on Synology, then browse, download and play files through File Station.

2. Method 1: Mount via File Station Remote Connection

If the target service already provides a WebDAV address (with an account and password), you can mount it directly with File Station's remote connection. The whole process is graphical and needs no extra package.

  1. Open File Station and go to Tools > Remote Connection > Connection Setup
  2. Click the icon to choose a protocol, tick WebDAV or WebDAV HTTPS, and click "Next"
  3. In the wizard, fill in the remote address, port, account and password to complete authentication
  4. Once set up, the remote service appears in the left panel of File Station and can be browsed like a local directory
Tip: WebDAV HTTPS encrypts the transfer and is more secure. If the other side only offers plain HTTP WebDAV, avoid transferring sensitive files over untrusted networks.

3. Method 2: Serve Files With the WebDAV Server Package

If you want another device (a phone, a computer or another NAS) to access your Synology the other way around, install the WebDAV Server package on Synology to expose your shared folders over WebDAV.

  1. Install and start WebDAV Server in Package Center
  2. Go to Settings > HTTP/HTTPS and tick "Enable HTTP" and "Enable HTTPS"
  3. Confirm the ports: the defaults are HTTP 5005 and HTTPS 5006, customizable as needed
  4. Click "Apply", then connect from File Station or a third-party client via Location > Connect to Server

Note that when the package serves files externally, always enable the firewall and account permission control so shared directories are not exposed to unauthorized access.

4. Limits of WebDAV for Chinese Cloud Drives

WebDAV is generic, but mounting Chinese cloud drives with it runs into several practical issues worth knowing in advance:

  • No open interface: most mainstream Chinese cloud drives such as Baidu Wangpan, Aliyun Drive and Quark Drive do not expose a WebDAV interface directly
  • Needs a third-party relay: mounting these drives usually requires a service like Alist to convert the drive protocol to WebDAV, which has a high deployment and troubleshooting barrier
  • Cumbersome multi-drive management: WebDAV typically connects to one remote at a time, so mounting several drives means adding connections over and over
  • No native features: WebDAV is only a file protocol and lacks drive-specific features such as offline caching, cross-drive transfer and QR-code login

6. FAQ

Q: Does Synology File Station support WebDAV?

A: Yes. In File Station, go to Tools > Remote Connection > Connection Setup and choose the WebDAV or WebDAV HTTPS protocol to connect a remote service. Once configured, the remote directory appears in the left panel.

Q: What are the default WebDAV ports on Synology?

A: When you enable the WebDAV Server package, the default HTTP port is 5005 and the HTTPS port is 5006. You can customize the ports under Settings > HTTP/HTTPS.

Q: Do Baidu Wangpan and Aliyun Drive support direct WebDAV mounting?

A: Most mainstream Chinese cloud drives do not expose a WebDAV interface directly. Mounting them usually requires a third-party relay such as Alist to convert the protocol, which has a high setup barrier. For direct mounting of Chinese drives, CloudMount's one-click mount is simpler.

Q: What is the difference between WebDAV mounting and CloudMount mounting?

A: WebDAV is a generic file protocol suited to configuring each WebDAV-capable service one at a time and normally mounts one remote at a time. CloudMount is natively integrated into Synology, mounts 8 major drives after a single QR login, and supports cross-drive transfer and offline caching.
