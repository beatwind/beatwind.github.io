How to Mount UC Wangpan on Synology NAS (Full Tutorial)

Use CloudMount to mount UC Wangpan as a local folder on your Synology NAS. Files saved in UC Browser are managed directly in File Station.

1. Why Mount UC Wangpan to Synology NAS

UC Wangpan is deeply integrated with UC Browser, and many users download and store resources through UC Browser. After mounting it to your Synology NAS:

  • Direct access to saved resources: files saved or transferred in UC Browser are accessible on your NAS right away
  • Unified management: manage all cloud drive files in one File Station interface
  • Expanded capacity: your UC membership storage effectively extends your NAS
  • Zero local storage usage: files stay in the cloud and use no NAS disk space

2. Installation Tutorial (3 Steps)

Step 1: Download CloudMount

Visit the official website to download the SPK package for your Synology model. All x86_64 Synology models are supported.

Download from Official Website →

Step 2: Install the Package

  1. Open the Synology DSM management interface
  2. Go to Package Center
  3. Click "Manual Install" in the top-right corner
  4. Select the downloaded SPK file
  5. Click Next, accept the agreement, and finish the installation

Step 3: Add UC Wangpan

  1. Open CloudMount
  2. Click "Add Cloud Drive"
  3. Select "UC Wangpan"
  4. Scan the QR code to log in with UC Browser or the UC Wangpan app
  5. Set the mount path and click OK
Done! Open File Station and you will see all your UC Wangpan files, just like a local folder.

4. FAQ

Q: Can free UC users use this?

A: Yes. Free users can mount and use UC Wangpan normally. UC members get more storage and lower download speed limits.

Q: Can I mount files shared by other UC users?

A: First save shared files into your own UC Wangpan, then access them through the mount. This is a common cloud drive API limitation.

Q: Will the phone UC Wangpan and NAS stay in sync?

A: Mounting accesses cloud files in real time, so new files uploaded from your phone appear in the NAS mount directory immediately, with no manual sync needed.

Q: UC Wangpan or Quark Drive, which is better to mount?

A: Both are Alibaba-family cloud storage. UC wins on UC Browser integration; Quark has more refined speed and membership plans. CloudMount supports 8 drives simultaneously, so mount both as needed.
