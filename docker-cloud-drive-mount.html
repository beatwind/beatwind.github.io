一、为什么要在Docker中访问网盘？

群晖 NAS 最大的优势之一就是 Docker 支持。很多人在群晖上跑 Jellyfin、Emby、Plex 等媒体服务器，但这些容器默认只能访问 NAS 本地存储。如果网盘里有大量视频想用 Jellyfin 播放，传统做法是先下载到本地再让容器扫描，既慢又占空间。

用 CloudMount 把网盘挂载到 NAS 本地目录后，Docker 容器可以直接映射这些目录，容器内的应用就能像访问本地文件一样读取网盘里的内容了。

二、原理说明

CloudMount 使用 FUSE 技术将网盘挂载为 /volume1/ 下的虚拟目录。Docker 容器在创建时通过 -v 参数将这些目录映射到容器内部，容器内看到的就是普通文件夹，实际数据从网盘实时读取。

挂载后的目录示例：

/volume1/baidu-netdisk/     ← 百度网盘
/volume1/aliyun-drive/      ← 阿里云盘
/volume1/quark-drive/       ← 夸克网盘
/volume1/115-drive/         ← 115网盘

三、安装CloudMount并挂载网盘

  1. 从下载页面获取 CloudMount SPK 安装包
  2. 在群晖套件中心「手动安装」SPK 文件，详见安装教程
  3. 打开 CloudMount，扫码登录你要挂载的网盘（支持百度网盘、阿里云盘等8个网盘）
  4. 挂载完成后，在 File Station 中确认网盘目录已出现

四、Jellyfin Docker配置

方法1：群晖 Container Manager 图形界面配置

  1. 打开 Container Manager（旧版叫 Docker）
  2. 创建或编辑 Jellyfin 容器
  3. 在「卷」设置中添加映射：
    • 本地路径：/volume1/baidu-netdisk/电影
    • 挂载路径：/media/电影
  4. 保存并启动容器
  5. 在 Jellyfin 管理界面添加媒体库，选择 /media/电影 目录

方法2：docker-compose 配置

version: "3"
services:
  jellyfin:
    image: jellyfin/jellyfin:latest
    container_name: jellyfin
    volumes:
      - /volume1/docker/jellyfin/config:/config
      - /volume1/docker/jellyfin/cache:/cache
      - /volume1/baidu-netdisk:/media/baidu
      - /volume1/aliyun-drive:/media/aliyun
      - /volume1/quark-drive:/media/quark
    ports:
      - "8096:8096"
    restart: unless-stopped

配置完成后，Jellyfin 会自动扫描网盘中的视频文件并刮削海报、字幕等信息。播放时视频从网盘实时流式传输，不占本地存储。详见Jellyfin播放网盘视频完整教程。

五、Emby/Plex Docker配置

Emby 和 Plex 的配置方法与 Jellyfin 完全相同，只需在容器卷映射中添加网盘目录即可：

# Emby
volumes:
  - /volume1/baidu-netdisk:/media/baidu
  - /volume1/aliyun-drive:/media/aliyun

# Plex
volumes:
  - /volume1/baidu-netdisk:/media/baidu
  - /volume1/aliyun-drive:/media/aliyun

映射后在 Emby/Plex 管理界面添加对应媒体库目录即可。

六、性能优化技巧

优化项 建议
网盘选择影音播放优先选阿里云盘/夸克网盘（不限速），冷数据选百度网盘
缓存设置CloudMount默认1GB缓存，播放大文件可适当增大缓存
转码注意网盘视频转码会占用NAS CPU，建议客户端直接播放（Direct Play）
并发控制同时播放多个网盘视频时注意带宽，建议限制并发转码数
目录结构网盘内按类型分文件夹（电影/电视剧/动漫），方便媒体库管理

七、常见问题

Q：Docker容器访问网盘文件速度怎么样？
A：取决于网盘速度。阿里云盘和夸克网盘不限速，Docker容器内播放4K视频也能流畅。百度网盘非会员限速约200KB/s。详见Jellyfin教程。
Q：容器内能看到网盘文件但播放失败怎么办？
A：检查容器是否有足够的权限访问挂载目录。在Container Manager中确认卷映射路径正确，容器运行用户有读取权限。也可能是网盘限速导致超时，建议换用阿里云盘测试。
Q：可以同时给多个Docker容器映射同一个网盘目录吗？
A：可以。多个容器可以同时映射同一个网盘目录，CloudMount会处理并发访问。但注意同时大量读取可能触发网盘限速。
Q：除了Jellyfin/Emby/Plex，还有哪些Docker容器可以用？
A：任何需要文件访问的容器都可以，比如 qBittorrent（下载到网盘）、Nextcloud（网盘文件同步）、Alist（网盘聚合）等。只要是能映射存储目录的Docker容器都能使用CloudMount挂载的网盘。
