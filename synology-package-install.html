一、什么是SPK套件包

SPK（Synology Package Kit）是群晖NAS的套件安装包格式，类似于 Windows 的 .exe 或 Android 的 .apk。群晖套件中心里大部分应用都是 SPK 格式，CloudMount 也是以 SPK 包形式分发的。

套件中心里的应用可以直接一键安装，但第三方开发的套件（如 CloudMount）需要通过「手动安装」功能来安装。

二、安装前提条件

条件要求
NAS架构x86_64（Intel/AMD处理器）
DSM版本7.0 或以上
存储空间至少100MB可用空间
网络能访问互联网（登录网盘需要）
管理员权限需要admin或root账户登录DSM

注意：CloudMount 仅支持 x86_64 架构的群晖NAS。DS220j、DS223j 等 ARM 架构的 value 系列无法安装。支持型号详见首页常见问题。

三、详细安装步骤

步骤1：下载SPK安装包

从下载页面获取 CloudMount 的 SPK 安装包，文件名为 webdav-mounter_x86_64.spk。下载到本地电脑即可。

步骤2：登录群晖DSM

在浏览器中输入群晖NAS的IP地址，登录 DSM 管理界面。需要有管理员权限的账号。

步骤3：打开套件中心

在DSM桌面找到「套件中心」图标并打开。这是群晖管理所有应用的地方。

步骤4：选择手动安装

在套件中心页面右上角找到「手动安装」按钮。如果看不到，可能需要点击右上角的菜单图标展开。

步骤5：上传SPK文件

在弹出的窗口中点击「浏览」，选择刚才下载的 webdav-mounter_x86_64.spk 文件，点击「下一步」。

步骤6：确认安装

系统会显示套件信息，确认无误后点击「安装」。安装过程通常只需几秒钟。

步骤7：打开CloudMount

安装完成后，在DSM桌面或主菜单中找到 CloudMount 图标，打开后即可开始挂载网盘。

整个安装过程不需要命令行、不需要SSH、不需要Docker，全程图形界面操作，3分钟即可完成。安装后可以参考我们的教程合集开始挂载网盘。

四、常见安装错误及解决

错误信息原因解决方法
无效的套件文件下载不完整或文件损坏重新下载SPK文件
此套件不支持您的NAS型号ARM架构机型不兼容更换x86_64架构NAS
DSM版本过低DSM版本低于7.0在更新设置中升级DSM
存储空间不足NAS硬盘空间不够清理文件释放空间
安装超时网络不稳定检查网络后重试

五、常见问题

Q：群晖怎么安装第三方套件？
A：在套件中心点击右上角的「手动安装」按钮，选择下载的SPK文件上传即可。不需要开启SSH或命令行操作，全程图形界面。详见上方安装步骤。
Q：安装CloudMount需要开启SSH吗？
A：不需要。CloudMount通过套件中心手动安装SPK文件即可，和安装官方套件的操作完全一样。安装后也可以参考Docker挂载教程进行进阶配置。
Q：CloudMount安装后在哪里打开？
A：安装后在DSM桌面或主菜单中找到CloudMount图标即可打开。打开后可以开始挂载百度网盘、阿里云盘等网盘。
Q：套件安装失败提示架构不匹配怎么办？
A：说明你的群晖NAS是ARM架构（如DS220j、DS223j等value系列），CloudMount目前仅支持x86_64架构。详见首页常见问题中的型号支持列表。
